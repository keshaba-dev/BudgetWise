A SIMPLE FLOW

From an entry to an insight.

The browser sends a request to the Java API. Java validates it, uses JDBC to query MySQL, then returns JSON for the page to display.

  1. 01Add an entryChoose income or expense, then add its details.
  2. 02Save it safelyA prepared statement stores it for the signed-in account.
  3. 03Review the monthSQL aggregates totals and budget progress.
